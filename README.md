# Data-Analysis-Web-Application
## Overview
A data analysis application created as part of a university web development course using html, css, and javascript to calculate analysis questions for a data set.
It features a file input section with analysis questions and an output area.

**Please see screenshots of the website in the data-analysis-web-app-screenshots file.

## Features
- Uploads and processes employee salary data from a JSON file.
- Calculates average employee salaries.
- Identifies divisions and departments with the highest employee counts and average salaries.
- Analyzes employee classifications, including full-time employment percentages and employee status distributions.
- Examines hiring trends by year and identifies departments with the most recent hires.
- Calculates the percentage of employees with exempt FLSA status.
- Displays results based on the selected analysis question.

## What I Learned
- To work with PHP to build server-side web applications.
- To use PHP arrays and loops to organize and analyze employee records.
- To implement filtering, counting, sorting, and averaging operations.
- To handle HTML form submissions and file uploads using POST requests.
- To connect HTML forms to PHP scripts for dynamic data processing.
- To apply statistical calculations to real-world employee data.
